# RIVA SystemVerilog Keyword Taxonomy

Every SystemVerilog reserved keyword belongs to exactly one lexical category.

This classification is used throughout the compiler.

---

1. Design Units
   Examples:
   module
   interface
   package
   program
   checker
   primitive
